# MedPipeline-Toolkit
Biomedical audit and monitoring toolkit
Features
- 🔍 System Audit (OS & Kernel information)
- 🐍 Python Dependency Check
- 📁 Clinical Folder Creation
- ❤️ Heart Rate Log Monitoring with Alerts
- 🧪 Research Manifesto Generator

---

## ⚙️ How It Works
The script performs the following steps:
1. Collects system information (OS, Kernel)
2. Checks if Python3 is installed
3. Creates folders for clinical data storage
4. Scans heart rate logs and detects critical conditions
5. Generates a research manifesto file based on user input
